# NSSI prediction model

Python code for the NSSI prediction models.

| File | Purpose |
| --- | --- |
| `nssi_model/model.py` | Preprocessing, feature selection, expert models, stacking and prediction. |
| `nssi_model/data.py` | Data loading, input validation, interface mapping and random seeds. |
| `nssi_model/evaluate.py` | Model evaluation, comparisons, ablations and statistical summaries. |
| `test_model.py` | Model and data-interface tests. |
| `requirements.txt` | Dependency versions used for testing. |
